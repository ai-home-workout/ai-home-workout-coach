# 데이터 수집 · 라벨링 가이드

> 담당: A. 데이터 · 최지민 (참여자 ID · 녹화 취합 · 라벨링 배정 · 일치도). **녹화는 각자 혼자, 편한 시간에 해요.** 라벨링도 모두 함께 해요.
> **영상은 찍지 않아요.** 웹 앱의 "데이터 녹화"가 웹캠에서 관절 좌표만 뽑아 JSON으로 저장하고, 라벨링은 그 좌표를 막대 인형으로 재생해서 해요. 얼굴이 나오는 파일이 생기지 않아서 저장소에 바로 올릴 수 있어요.
> 오류 기준(5절)은 **녹화 전 킥오프에서 합의**해요. 기준이 바뀌면 이미 단 라벨도 다시 봐야 해요.

전체 흐름:

```
[녹화] 웹 앱 "데이터 녹화" → P01_side_good_01.json 내려받기 → data/coords/에 넣고 커밋
[라벨] 웹 앱 "라벨링" → 좌표 JSON 열기 → 반복마다 시작·끝·정상/오류 표시 → labels/<아이디>.csv 내려받기 → 커밋
[검수] npm run kappa → 두 사람 판정이 다른 반복을 같이 보고 labels/final.csv 확정
[평가] npm run eval -- --coords data/coords --labels labels/final.csv
```

---

## 1. 준비 (한 번만)

1. 저장소를 받고 웹 앱을 띄워요.
   ```bash
   git pull
   cd web && npm install && npm run dev
   ```
2. **Chrome**에서 http://localhost:5173/?tab=record 를 열어요. 카메라 권한을 허용해요.
3. 처음에는 자세 인식 모델을 내려받느라 몇 초 걸려요(인터넷 필요).

## 2. 참여자 ID

- 참여자마다 `P01`, `P02`, … 를 하나씩 정해요. A 담당이 단톡방으로 각자에게 알려 줘요. **실명은 저장소 어디에도 쓰지 않아요.**
- 실명 ↔ ID 표는 팀 드라이브(저장소 밖)에만 둬요.
- 팀원 4명이 우선 `P01`~`P04`. 사용자 평가 참여자는 `P05`부터 이어서 써요.
- 녹화 전에 참여자에게 알려요: 영상은 저장하지 않고, 관절 좌표(점 33개의 위치)만 저장해서 공개할 수 있다는 것.

## 3. 카메라 배치 (측면)

| 항목 | 기준                                                              |
| ---- | ----------------------------------------------------------------- |
| 위치 | 몸 옆 2~3m, 노트북 카메라가 골반 높이쯤 오게 (책 · 의자로 받쳐요) |
| 화면 | 머리부터 발끝까지 다 보이고 위아래로 여유가 조금 있게             |
| 방향 | 몸의 왼쪽이나 오른쪽이 카메라를 향하게. 녹화 중에 바꾸지 않아요   |
| 환경 | 밝은 곳, 몸에 붙는 옷, 뒤에 다른 사람이 지나가지 않게             |

화면에 막대 인형이 몸에 딱 붙어 따라오면 준비 완료예요. 관절이 주황색이면 잘 안 보이는 거예요.

## 4. 녹화 계획 (1인 약 15분)

웹 앱의 "테이크" 목록과 같아요(`web/src/record/takes.js`). 테이크 하나가 JSON 파일 하나예요.

| 테이크                  | 파일 이름 예                | 내용                                                                      | 횟수 |
| ----------------------- | --------------------------- | ------------------------------------------------------------------------- | ---- |
| 측면 · 정상             | `P01_side_good_01.json`     | 평소처럼 정확한 자세                                                      | 10   |
| 측면 · 깊이 부족        | `P01_side_shallow_01.json`  | 허벅지가 수평이 되기 전에 올라오기                                        | 5    |
| 측면 · 상체 과도 숙임   | `P01_side_lean_01.json`     | 깊이 앉되 상체를 45° 넘게 숙이기                                          | 5    |
| 측면 · 날림 동작        | `P01_side_fast_01.json`     | 빠르게, 바닥에서 튕기듯 (다치지 않게 무리하지 않아요)                     | 5    |
| 측면 · 섞어서           | `P01_side_mixed_01.json`    | 정상 → 얕게 → 정상 → 숙이기 → 빠르게 → 정상 → 얕게 → 정상 → 숙이기 → 정상 | 10   |
| 측면 · 가려짐           | `P01_side_occluded_01.json` | 발 · 무릎이 화면 밖으로 나가게 카메라를 낮추거나 다가가서 정상            | 5    |
| 정면 · 정상 (선택)      | `P01_front_good_01.json`    | 멘토링 후 정면 판정용                                                     | 10   |
| 정면 · 무릎 모임 (선택) | `P01_front_valgus_01.json`  | 앉을 때 무릎을 안쪽으로 모으기                                            | 5    |

- **각 테이크는 시작 전후 2초씩 가만히 서 있고, 반복 사이에도 1~2초 서 있어요.** 반복 경계가 분명해야 라벨링이 쉬워요.
- 같은 테이크를 다시 찍으면 번호가 `_02`, `_03`으로 올라가요. 마음에 안 드는 파일은 커밋하지 않으면 돼요.
- 다치지 않는 게 먼저예요. 오류 동작은 흉내만 내도 되고, 힘들면 쉬어요.

## 5. 녹화하기

**혼자 해요.** 영상이 아니라 좌표만 저장되니까 다른 사람과 시간을 맞출 필요가 없어요. 녹화 시작을 누르면 5초 카운트다운이 있어서 제자리로 갈 시간이 있고, 끝낼 때는 노트북으로 걸어가 Space를 누르면 돼요(끝 2초 서 있기 뒤라 괜찮아요).

1. "데이터 녹화" 탭에서 **참여자 ID**(예: `P01`)를 쓰고 **테이크**를 골라요.
2. 오른쪽에 나온 안내(내용 · 횟수)를 운동하는 사람에게 읽어 줘요.
3. **녹화 시작**(또는 Space) → 5초 카운트다운 동안 제자리로 가서 서요.
4. 화면 오른쪽 위에 "● 녹화 중"이 뜨면 2초 서 있다가 시작해요. 다 하면 2초 서 있어요.
5. **녹화 끝**(또는 Space)을 눌러요.
6. 결과를 확인해요: 좌표 프레임 수, FPS(15 이상이면 좋아요), **사람 인식 비율**(80% 미만이면 다시 찍기를 권해요. 가려짐 테이크는 낮아도 괜찮아요).
7. **저장**을 누르면 `P01_side_good_01.json`이 다운로드 폴더에 내려받아져요. 다시 찍으려면 "버리고 다시 찍기".
8. 계획표의 테이크를 모두 찍을 때까지 1~7을 반복해요.

## 6. 파일 올리기

1. 다운로드 폴더의 JSON을 저장소 `data/coords/`로 옮겨요.
2. 형식을 검사해요.
   ```bash
   npm run check:coords -- data/coords
   ```
3. 자기 브랜치에 커밋하고 푸시한 뒤 PR을 올려요.
   ```bash
   git add data/coords
   git commit -m "[data] P01 측면 좌표 녹화 추가"
   git push
   ```

## 7. 정상 / 오류 기준 (라벨 기준)

반복 하나에 오류가 여러 개면 모두 표시해요.

| 오류           | 확인 방향 | 오류로 보는 기준 (초안)                                                |
| -------------- | --------- | ---------------------------------------------------------------------- |
| 깊이 부족      | 측면      | 가장 깊이 앉았을 때 허벅지(엉덩이–무릎 선)가 바닥과 수평보다 확실히 위 |
| 상체 과도 숙임 | 측면      | 상체(어깨–엉덩이 선)가 수직에서 45° 넘게 앞으로 숙여짐                 |
| 무릎 모임      | 정면      | 앉거나 일어설 때 무릎이 발목보다 안쪽으로 모임                         |
| 날림 동작      | 모두      | 1회가 약 0.8초보다 짧거나, 바닥에서 튕기듯 반동으로 올라옴             |

- **정상**: 위 오류가 하나도 없음
- **판단 불가**: 관절이 화면 밖이거나 가려져서 볼 수 없음. 정상으로 표시하지 않아요.
- 그 방향에서 볼 수 없는 오류는 표시하지 않아요(정면 파일에서 깊이 부족은 표시 안 함).
- **파일 이름(테이크 종류)이 아니라 눈에 보이는 대로** 표시해요. "깊이 부족" 테이크라도 실제로 깊이 앉았으면 정상이에요.
- 애매하면 단톡방에 파일 이름과 시각을 올려서 물어보고, 합의한 사례는 아래 "사례 모음"에 적어요.

## 8. 반복 경계

- **시작(S)**: 서 있다가 무릎이 굽기 시작하는 순간
- **끝(E)**: 다시 다 일어선 순간
- 반복 사이에 서 있는 시간은 어느 반복에도 넣지 않아요.

## 9. 라벨링하기

1. Chrome에서 http://localhost:5173/?tab=label 을 열어요.
2. **라벨러**에 자기 GitHub 아이디를 써요. 라벨은 브라우저에 자동 저장되고, 아이디별로 따로 보관돼요.
3. **좌표 JSON 열기**로 `data/coords/`의 배정받은 파일을 열어요(여러 개 한 번에).
4. 막대 인형을 0.5배속으로 재생하면서 반복마다:
   - 시작 순간에서 멈추고 **S**, 끝 순간에서 멈추고 **E** (←/→로 1프레임씩 맞춰요)
   - 오류가 보이면 체크, 안 보이면 체크 없이(정상), 볼 수 없으면 "판단 불가"
   - **Enter**로 반복 추가. 타임라인에 초록(정상) · 빨강(오류) 막대가 생겨요
5. 잘못 넣은 반복은 오른쪽 목록에서 **삭제**하고 다시 넣어요.
6. 다 하면 **CSV 내려받기** → `<아이디>.csv`를 저장소 `labels/`에 넣고 커밋해요.
   ```bash
   git add labels/SYW77.csv
   git commit -m "[data] P01 · P02 라벨 추가"
   ```
7. 다른 컴퓨터에서 이어서 하려면 **CSV 불러오기**로 내 CSV를 불러와요(지금 브라우저의 라벨을 덮어써요).

단축키: Space 재생/정지 · ←/→ 1프레임 · Shift+←/→ 1초 · S 시작 · E 끝 · Enter 반복 추가

## 10. 2인 라벨링과 일치도 (A 역할)

1. 파일마다 라벨러 2명을 배정해요. **자기가 운동한 파일은 라벨링하지 않아요.** 배정표는 아래에 적어요.
2. 두 사람은 서로의 CSV를 보지 않고 따로 라벨링해요.
3. 둘 다 올라오면 일치도를 재요.
   ```bash
   npm run kappa -- labels/<A>.csv labels/<B>.csv
   ```
   - "판정이 다른 반복": 두 사람이 같이 보고 최종 판정을 정해요.
   - "한쪽에만 있는 반복": 반복 경계를 다르게 잡은 거예요. 같이 보고 맞춰요.
4. 합의한 결과를 `labels/final.csv`로 만들어요(한 사람의 CSV를 복사해서 고치면 돼요. `labeler` 열은 `final`).
5. 평가를 돌려요.
   ```bash
   npm run eval -- --coords data/coords --labels labels/final.csv
   ```

### 부록: 영상으로 찍은 경우

스마트폰 영상밖에 없을 때만 써요. 영상 원본은 **저장소에 올리지 않고** 팀 드라이브에만 둬요.
파일 이름을 위 규칙(`P01_side_good_01.mp4`)대로 지은 뒤 좌표만 뽑아요.

```bash
pip install -r extract/requirements.txt
python extract/extract_pose.py <영상 또는 폴더> -o data/coords/
```

모델 파일 `models/pose_landmarker_full.task`가 필요해요(README 참고). 이후 라벨링은 같은 방법이에요.
