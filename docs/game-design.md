# 게임 요소 규칙 (초안 · 담당: 손연우)

> 할 일 D1. 아래 "지켜야 할 원칙"은 과제 계획서와 `AGENTS.md`에서 이미 정한 거예요. "정할 것"을 채워서 확정해요.
> 확정하면 D2(로직)과 D3(화면)는 이 문서를 기준으로 만들어요.

## 지켜야 할 원칙

- **정자세만 보상**: 콤보 · 뱃지 · 경험치 · 스트릭은 정상(`valid: true`) 반복에만 연동해요. 오류 반복, 날림 동작, 판정 보류는 보상하지 않아요.
- **판정 보류는 콤보를 끊지 않아요.** 카메라 문제는 사용자 잘못이 아니에요.
- **오류에 큰 페널티를 주지 않아요.** 콤보가 0으로 돌아가는 것 말고는 깎지 않아요(경험치 감소, 레벨 하락 없음).
- **속도 경쟁 금지**: 시간 제한, 빨리 하기, 횟수 랭킹, 다른 사람과 비교는 만들지 않아요.
- **무리한 운동 유도 금지**: 연속 오류 휴식 권유가 게임 요소보다 우선이에요. 스트릭에는 휴식일 보호를 넣어요.
- **끌 수 있어야 해요**: `?game=0`이면 모든 게임 요소가 화면에서 사라지고 판정 · 카운트는 같아야 해요(사용자 평가에서 두 조건에 똑같이 적용).
- **데이터**: 게임 진행 정보도 브라우저에만 저장해요. 영상이나 좌표는 저장하지 않아요.

## 입력: UI 이벤트

게임 로직은 판정 로직이 내보내는 UI 이벤트(`shared/README.md` ③)만 받아요.

| 이벤트                                | 게임에서 쓰는 곳                   |
| ------------------------------------- | ---------------------------------- |
| `rep` (`valid: true`)                 | 콤보 +1, 경험치 +?                 |
| `rep` (`valid: false`, `held: false`) | 콤보 0                             |
| `rep` (`held: true`) · `hold`         | 아무것도 바꾸지 않음               |
| `setDone`                             | 세트 클리어 뱃지 판단              |
| `rest`                                | (정할 것) 휴식 권유를 따르면 보상? |

지금 운동 화면(`web/src/components/WorkoutScreen.jsx`)에는 **콤보와 최고 콤보만** 임시로 들어가 있어요. D2에서 `web/src/game/`으로 옮겨요.

## 계획서에 적은 요소

| 요소             | 계획서 내용                                        |
| ---------------- | -------------------------------------------------- |
| 연속 성공 콤보   | 정상 자세를 연속으로 성공한 횟수                   |
| 세트 클리어 뱃지 | 설정한 세트의 횟수를 정상 자세로 모두 채우면 지급  |
| 레벨업           | 누적 정상 반복 수 기준 경험치                      |
| 연속 운동 스트릭 | 연속으로 운동한 일수, 주간 목표와 휴식일 보호 적용 |

## 정할 것

- [ ] **콤보**: 화면에 언제부터 보여 줄까요(2콤보부터?). 콤보 기록(최고 콤보)을 저장할까요?
- [ ] **세트 클리어 뱃지**: 정상만 세니까 세트를 끝내면 항상 "정상으로 모두 채운" 상태예요. 그러면 뱃지 조건을 무엇으로 할까요?
  - 예: 세트 안에서 오류 반복이 n개 이하 / 그 세트 동안 콤보가 끊기지 않음 / 처음 끝낸 세트 수 기념
- [ ] **경험치 · 레벨**: 정상 반복 1회당 경험치, 레벨별 필요 경험치(예: 레벨 n → n×50). 레벨 이름이나 칭호가 필요할까요?
- [ ] **스트릭**: "운동한 날"의 기준(정상 반복 몇 회 이상?), 주간 목표(주 n일), 휴식일 보호(주 m일까지 빠져도 유지?)
- [ ] **수준(초급/경력)별 차이**: 같은 규칙? 초급은 뱃지 조건을 느슨하게?
- [ ] **완료 화면**: 이번 운동에서 얻은 경험치 · 뱃지 · 스트릭 변화를 어떻게 보여 줄까요?

## 사용자 평가와의 관계

- 평가는 "피드백 있음 vs 없음"을 비교해요. 게임 요소는 **두 조건에 똑같이 켜거나 똑같이 꺼요.**
- 조건 전환: `?feedback=0`, `?game=0` (`web/src/appConfig.js`)
